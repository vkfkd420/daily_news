# Daily Briefing 데이터

ChatGPT **프로젝트-뉴스**에서 매일 9시에 받은 JSON을 여기에 두거나,  
앱에서 **「ChatGPT에서 가져오기」**로 붙여넣으면 됩니다.

## 파일 규칙

- 경로: `data/briefings/YYYY-MM-DD.json`

## JSON 스키마

`date`, `title`, `summary`, `riskLevel`, `marketDrivers`, `news`, `portfolioInsight` — 자세한 필드는 프로젝트 GPT 지시문과 동일하게 유지하세요.

샘플: `2026-05-26.json`
