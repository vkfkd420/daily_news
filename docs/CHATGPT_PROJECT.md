# 프로젝트-뉴스 연동 (ChatGPT Plus)

ChatGPT **Plus 구독**으로 브리핑을 만들고, 앱에 넣는 방법입니다. **API 추가 결제는 필요 없습니다.**

→ 상세: **[CHATGPT_PLUS.md](./CHATGPT_PLUS.md)**

## 요약

1. 프로젝트 지시문 = `data/prompts/project-news-instructions.md` 내용 복사
2. 매일 채팅 = `data/prompts/chatgpt-daily-prompt.txt` (또는 "오늘 JSON 브리핑")
3. 앱 = **「ChatGPT에서 붙여넣기」**

채팅 기록을 API로 읽는 기능은 없습니다. (완전 무인 자동은 [AUTOMATION_SETUP.md](./AUTOMATION_SETUP.md)의 OpenAI API 방식만 가능)
